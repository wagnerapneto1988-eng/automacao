WAP PROSPECÇÃO V1

Arquivos:
- index.html
- style.css
- app.js

Como publicar:
1. Extraia o ZIP, se a hospedagem exigir.
2. Envie os três arquivos mantendo-os na mesma pasta.
3. Abra index.html pela hospedagem.

Funcionalidades da V1:
- Dashboard com métricas.
- Cadastro e edição de potenciais clientes.
- Busca e filtro por status.
- Classificação da oportunidade.
- Follow-up por data.
- Geração automática de abordagem.
- Botão para abrir WhatsApp com mensagem pronta.
- Mudança automática de status para "Contato realizado".
- Armazenamento local via localStorage.

Observação:
Os registros ficam salvos no navegador/dispositivo usado. A V2 será preparada para PHP + MySQL, permitindo login, banco central e acesso por vários dispositivos.
